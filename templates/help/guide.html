AI Models & Important Notes

{% if language == 'tl' %} Disease detection ay gumagamit ng TFLite CNN: mag-upload ng malinaw na leaf photo; confidence below the configured threshold ay ikokonsiderang "Unknown/Not Rice". Yield prediction may tatlong mode: Linear (tabular), CNN (canopy image), at Ensemble (pareho). Admin ang nagta-toggle ng CNN yield. {% else %} Disease detection uses a TFLite CNN: upload a clear leaf photo; confidence below the configured threshold will be treated as "Unknown/Not Rice." Yield prediction has three modes: Linear (tabular), CNN (canopy image), and Ensemble (combined). Admins toggle CNN yield availability. {% endif %}

{% if language == 'tl' %}Paano basahin ang AI result at confidence?{% else %}How to read AI results and confidence?{% endif %}

{% if language == 'tl' %}Ang result ay may label at confidence percentage. Kung ang confidence ay mas mababa sa admin-configured threshold (karaniwan 75%), ipapakita ito bilang "Unknown/Not Rice" upang maiwasan maling diagnosis. Tingnan din ang severity para sa treatment intensity.{% else %}The AI result includes a label and a confidence percentage. If confidence is below the admin-configured threshold (commonly 75%), it will be shown as "Unknown/Not Rice" to avoid false positives. Also review severity to choose treatment intensity.{% endif %}

{% if language == 'tl' %}Bakit low confidence ang scan?{% else %}Why is the scan confidence low?{% endif %}

{% if language == 'tl' %}Karaniwan itong nangyayari kapag malabo, madilim, o hindi rice leaf ang image. Kumuha ulit ng mas malinaw na photo.{% else %}This usually happens when the image is blurry, dark, or not a rice leaf. Take another clearer photo.{% endif %}
